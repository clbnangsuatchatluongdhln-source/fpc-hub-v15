Nếu có lỗi, đi đường nào?

① Xác định ô bị lỗi → ② mở các tệp trong ô → ③ đọc sổ thay đổi và checkpoint → ④ so sánh, phục hồi đúng tệp bị ảnh hưởng → ⑤ kiểm tra lại và cập nhật map. Không khôi phục toàn bộ repo đang có công việc dở.

Sửa xong: cập nhật mô tả trong map kỹ thuật và script tạo bản hình → npm run map:update → npm run map:check. Kiểm tra hash chỉ phát hiện mã đổi, không tự xác nhận mô tả đúng.
